# Catálogo de Productos 📦🛡️

Una aplicación de escritorio robusta para la gestión y administración de inventarios, desarrollada en C# utilizando la interfaz gráfica de Windows Forms.

## 🛠️ Tecnologías y Herramientas

* **Lenguaje Principal:** C# (.NET Framework / .NET Core)
* **Interfaz Gráfica:** Windows Forms (WinForms)
* **Arquitectura:** Diseño en capas (Capa de Dominio y Capa de Negocio)
* **Entorno de Desarrollo:** Visual Studio (`.sln`)
* **Control de Versiones:** Git & GitHub

## ✨ Características Principales

* **Arquitectura en Capas:** Separación limpia de responsabilidades mediante una capa de `dominio` (modelado de datos del producto) y una capa de `negocio` (lógica de la aplicación y comunicación).
* **Gestión de Inventario (CRUD):** Interfaz preparada para el alta, baja, modificación y lectura de artículos y productos.
* **Interfaz de Escritorio Intuitiva:** Controles nativos de Windows para una navegación fluida, rápida y enfocada en la productividad del usuario.
* **Consistencia de Datos:** Estructura modular que facilita la futura conexión a bases de datos (como SQL Server) a través de la capa de negocio.

## 💡 Sobre el desarrollo

Este proyecto fue desarrollado de forma grupal (Equipo 1B) como un trabajo práctico enfocado en el diseño de software comercial. El objetivo principal fue implementar las mejores prácticas de la Programación Orientada a Objetos en C#, asimilar la separación de lógica y presentación mediante la arquitectura en capas, y coordinar el desarrollo de código limpio de manera colaborativa utilizando Git.
